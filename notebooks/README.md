# Notebooks

Use this folder for sequential, reproducible analysis notebooks.

Recommended order:
1. 01_data_quality.ipynb — source profiling, missing values, duplicates, and validation.
2. 02_data_integration.ipynb — key mapping, joins, and reconciliation checks.
3. 03_exploratory_analysis.ipynb — sales trends, category mix, discounting, returns, and inventory.
4. 04_demand_forecasting.ipynb — baseline forecasts, time-based validation, MAE/WAPE, and bias.

Each notebook should state its question, data source, date range, assumptions, methods, results, and business implication. Do not include fabricated findings; label synthetic data clearly.
